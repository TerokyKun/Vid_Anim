# Vid_Anim — анимация любого рига по видео или по примеру анимации

Локальный аддон для Blender, который переносит человеческую анимацию с одного арматура на другой и бэкает результат в ключевые кадры. Два варианта работы:

1. **По примеру анимации** — FBX / BVH / GLB / DAE. Работает только средствами Blender, без внешних зависимостей.
2. **По видео** — с помощью бэкенда на MediaPipe извлекаются 3D-маркеры движения, после чего используется тот же алгоритм переноса анимации.

Всё работает полностью оффлайн, без аккаунтов и без отправки данных в сеть.

## Структура

```
blender_addon/vid_anim/   — аддон для Blender (чистый Python, использует только bpy)
backend/                — опциональный бэкенд для извлечения позы из видео (собственное venv)
_dev/                   — вспомогательные тесты и эксперименты
```

## Установка аддона

Требуется Blender 4.2+ (проверено на 5.0).

- Зипнуть папку `Vid_Anim` (ту, где лежит `__init__.py`) и установить через **Edit > Preferences > Add-ons > Install from Disk**.
- Либо скопировать `blender_addon/vid_anim` в директорию `scripts/addons` Blender'а.
- Включить аддон **Vid_Anim** и открыть вкладку **Vid_Anim** в сайдбаре 3D Viewport (**N**).

## Быстрый старт — по примеру анимации

1. **Источник** → `Import animation (FBX/BVH)`. Импортированная арматура станет **Source**.
2. **Целевой риг** → выбрать **Target**. Кнопка `Preview bone mapping` выведет авто-совпадение костей в системный консоль Blender.
3. **Диапазон и настройки** → по умолчанию **Auto range** включён. При необходимости выставить **Facing offset** (0 или 180), если ориентация источника отличается от цели.
4. **Ретаргет и бэйк** → `Retarget & Bake`.

Автосопоставление костей работает по семантике имён: определяются `upperarm/forearm/thigh/shin/hand/foot`, левая/правая стороны, спина/шея/голова. IK-цепи временно обходятся, чтобы после бэйка именно FK-контролы формировали финальную анимацию.

## Быстрый старт — по видео

Однократная настройка бэкенда в папке `backend/`:

- Windows: `setup_windows.bat` (установит `mediapipe`, `opencv-python`, `numpy`)
- Linux/WSL: `./setup_venv.sh`

Затем в панели **Video mocap**:

1. Выбрать **Video** файл.
2. Указать **Backend Python** — путь к интерпретатору venv (`backend\venv\Scripts\python.exe` на Windows, `backend/venv/bin/python` на Linux).
3. Выбрать **Model** (`full` — оптимальный вариант по умолчанию).
4. Нажать `Extract motion from video`.

Бэкенд создаст `<имя_видео>_pose.json` с 3D-маркерами в метрической системе для каждого кадра. Аддон автоматически построит временный источник по JSON и, если задан **Target**, сразу выполнит перенос анимации с бэйком. Также можно использовать готовый JSON через `Build source from pose JSON`.

При первом запуске MediaPipe скачает модель в `~/.Vid_Anim/`.

## Как работает

- **Ядро переноса анимации** (`retarget.py`): для каждой сопоставленной кости берётся мировая ориентация кости источника и применяется к целевой (с учётом **Facing offset**). Голова кости цели остаётся на месте, а корень сохраняет собственное перемещение.
- **Сопоставление костей** (`bone_maps.py`): семантический классификатор имён с приоритизацией — отдаёт предпочтение FK/деформ-контролам перед IK/organisation/tweak-костями.
- **Построение по видео** (`mocap.py`): строится каноническая T-поза-арматур, а для каждого кадра ориентация костей вычисляется по направлению от сустава к дочернему суставу на основе 3D-маркеров MediaPipe.

## Зависимости

- **Аддон**: только встроенный `bpy` Blender'а, внешние PyPI-зависимости не требуются.
- **Бэкенд (опционально)**: `mediapipe>=0.10.9`, `opencv-python>=4.8`, `numpy>=1.24`.
